Exact instructions & tools

The full prompt comes from the retained binding manifest. The comparison extracts are derived from those exact texts; they are not separate prompts sent to a model. Per-turn context messages and vendor-internal instructions are not reconstructed here.

Assessment setup

ASR and judge settings come from observations in the selected re-scored report. They describe that assessment revision, which can differ from the original scoring. Empty judge lists mean no judge is listed for those observations. Judge prompt template identifiers are shown where retained; exact judge prompt text is not present in these artifacts. The caller’s exact voice configuration is also not recorded here.

Evidence & verification

This page checks the saved instruction and tool hashes and compares the requested setup with the retained binding manifest. It does not re-read run ledgers or perform Ed25519 signature verification. A matching hash establishes consistency with these files, not proof of what a vendor executed.
