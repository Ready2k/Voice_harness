## Interpretation

This is a captioned screenshot animation, not continuous footage of a live evaluation. No calls or paid evaluations were launched for the promo. The captures preserve actual setup gaps and credit warnings. Six verified families does not mean six ready-to-run configurations on the captured server.

The local five-provider report shown in the movie is a historical UI snapshot. It differs from the updated published report with replacements and GPT-Live carry-over used in the presentation. Use the presentation and its source brief for the current numerical conclusions. Counts in the Runs page are only the latest displayed records.

The live AI caller and telephone features are bounded pilots. A registered scenario runner is still needed after importing a definition. Holds preserve retained evidence and cannot recover purged data. One owner identifier was obscured for privacy. Live provider calls still use configured cloud services even though the UI and evidence workflow run locally.

The video has no narration or music. Captions carry the message; pause to examine individual controls.
