PROMPT TUNING MATTERS

Targeted instructions move individual results; broad tuning did not move the ranking.

Every provider was given the same standard prompt, so this comparison is fair, but it describes that prompt. Giving each vendor its own tuned wording (the 28 October run) left five of six composites within 0.004 of the standard run; OpenAI Realtime differed by 0.027, but that run predates later harness fixes, so it is not a clean comparison. Nova's two weakest scenarios failed the same way under both. In a separate 30 October diagnostic, two targeted prompt lines (use the human-handoff tool when asked; pass identifiers exactly as spoken) moved Nova from calling the handoff tool in 1 of 3 runs to 3 of 3, and from 0 of 3 to 2 of 3 on a transaction lookup. That check is small and is not part of any score. Treat a tie on quality as "tied under this prompt": what the prompt says about a task can matter more than how it is styled. Read the run notes

HOW TO READ THIS DASHBOARD

Evidence first. Comparisons with context.

One run, one count

All experiments uses the preferred assessment of each experiment, then deduplicates by run ID. Re-scores and cost revisions remain selectable versions. Retry attempts are counted separately from final runs. Preflight checks are not scored runs.

Missing is not zero

Not recorded, not applicable, failed and unresolved results stay distinct. Older exports have fewer fields. Task completion needs a completed run with expected tools; explicit exclusions are retained. Factual checks exclude recorded no-claim passes.

Timing and cost have limits

First-audio times exclude overlapping turns. Turn control, anchors and estimates differ: no speed winner is inferred. Cost uses historical report tariffs, covers provider voice usage, and excludes shared assessment overhead. Known spend can be incomplete.

Coverage is explicit

Recorded model labels are historical metadata, not independently verified vendor versions. No customer satisfaction, production readiness or Connect performance is inferred.
