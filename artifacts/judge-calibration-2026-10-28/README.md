# Judge calibration follow-up — 28 October 2026

Follow-up to the fair-harness bake-off. No voice sessions, ASR calls or original judge assessments are repeated. The historical bake-off observations retain their original calibration bindings.

Two judges: OpenAI `gpt-6-sol` and AWS Bedrock `us.anthropic.claude-haiku-4-5-20251001-v1:0`, using `offline-judge/1` / `eval-1`. Each receives all 240 `holdout-v1` examples (24 expected passes and 24 expected failures for each of five criteria). Three concurrent requests per judge, separate backend per request; one logical evaluation per example, no outcome-based retries. OpenAI's existing adapter may retry without temperature when the API rejects that parameter; the resulting call metadata is retained. Requests and the normal evaluation pipeline are unchanged. Raw replies are replayed locally through `evaluate_holdout` to validate citations and compute the standard policy measurements; replay does not make API calls.

## What this validates

This is a **synthetic fixture benchmark**, not independent human validation. Expected labels, `reviewer_a` and `reviewer_b` are generated by `holdout.py`; the latter fields simulate reviewer agreement. Their reported agreement statistic is not measured human agreement. Audio fixtures are silence with scripted metadata, so the benchmark does not validate ASR or listening quality. Examples are checked disjoint from the built-in tuning set, but structural similarity and one pass limit generalisation.

Default policy thresholds are exploratory. Policy approval remains false, and no blocking behaviour is enabled. Passing numeric checks is evidence for this fixture set only, not production certification. Current rubric versions are used; historical results are not retrospectively rebound or rescored. An earlier Haiku report exists in `artifacts/phase4`, but was not bound to the bake-off; this follow-up does not erase it.

## Reproduction and artifacts

From the repository root: `PYTHONPATH=src .venv/bin/python artifacts/judge-calibration-2026-10-28/runner.py`. This incurs judge API calls and reads existing ignored `.env` and `.local/aws-session.env` credentials without printing them. Each judge has a standard report, policy and example-level raw-response archive. The report fingerprints model, prompt template, evaluation version, policy hash and holdout content hash. No credentials or private keys are included. Provider billing cost is not recorded by this runner, so no monetary total is claimed.
