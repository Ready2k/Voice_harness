03 / Local deployment boundaries

Compose fixtures and host live runs use separate service instances and data directories. The default macOS caller uses say / afconvert; openai_tts is an opt-in alternative. This view describes local development, not a production deployment.

Live-run telemetry: both API instances initialise telemetry.py. Exporters are enabled only when OTEL_EXPORTER_OTLP_ENDPOINT is set. Compose sets it to http://otel-collector:4318; make serve-live can inherit it from the environment or .env, but sets no default and starts no collector. The Compose collector is not exposed to the host. Live export therefore needs a separately reachable collector or an explicitly configured connection to the existing one. The diagram shows this capability, not a verified running connection.
