# Work log

Your own notes on the evidence you discuss. Each entry is a Markdown file in this folder, listed in `logs.json`, and shown at `work-logs/index.html` (open it through `python3 serve.py`).

- Add an entry: `python3 work-logs/new_log.py "Review with the platform team"`, then edit the new `.md` file.
- Entries stay in this folder. They are not part of the published site, so the GitHub Pages build never includes them.
- When you download a newer bundle, copy this folder across to keep your notes.
