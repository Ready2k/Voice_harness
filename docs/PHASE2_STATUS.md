# Phase 2 status (shared layer)

Honest state: the shared layer is in place; **no provider is `implemented_and_verified`**, so the verified count is 0 of 4 until AC-09 passes for a live adapter.

- `src/voice_harness/adapters/__init__.py`: `LiveAdapter` protocol (MockProvider operations plus `interrupt(item_id, audio_end_ms)`) and closed pydantic events (audio_out, transcript delta/final, tool_call, turn start/end, interrupted, usage, error). Unsupported truncation is signalled by `capabilities()["interrupt_truncate"] == "unsupported"` and `CapabilityUnsupported`.
- `src/voice_harness/resample.py`: stdlib integer linear resampler (any rate pair, 16k<->24k tested), 20 ms chunker. Linear interpolation without an anti-alias filter: adequate for speech fixtures, not a quality claim.
- `coverage.py` (AC-20): state derives from `artifacts/phase0/*-capability-report.json` plus an adapter module being present. `implemented_and_verified` requires: adapter present, report valid, not expired, not failed-closed, and `artifacts/phase2/<family>-ac09.json` with `passed: true`, no failures and a `capability_report_id` equal to the report. Otherwise `implemented_but_unverified` (reasons `REPORT_EXPIRED`, `REPORT_FAILED_CLOSED`, `AC09_NOT_PASSED`, `NO_CAPABILITY_REPORT`); no adapter gives `not_implemented`. xAI and Google stay `not_implemented`. Nothing is ranked (`ranking: null`) and `verified_count` counts verified states only.
- API: `GET /api/v1/providers` and `GET /api/v1/providers/export` (same payload, with `statement`). Directories overridable by `HARNESS_PHASE0_DIR` / `HARNESS_PHASE2_DIR`. The Docker image does not copy `artifacts/`, so inside the container families report `NO_CAPABILITY_REPORT` unless those directories are mounted. No UI panel yet (AC-20 "UI" part is open).
- `tests/adapter_conformance.py` (AC-09 harness): dimensions audio_in, audio_out, tool_result_correlation, interruption, error; unsupported dimensions are `excluded` with a reason, and exclusion of a mandatory dimension prevents `passed`. Proven only against a MockProvider wrapper in `tests/test_phase2.py`. Live runs are opt-in: `VOICE_HARNESS_LIVE_ADAPTERS=openai,aws_nova_sonic` requires each adapter module to expose `conformance_factory() -> (adapter, prime)`; `write_result()` stores the result bound to a capability report.
- Not done: live AC-09 runs, UI coverage panel, bundle-manifest embedding of coverage.
