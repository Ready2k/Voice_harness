# Phase 2 status (shared layer)

Honest state: the shared layer is in place; as of 2026-10-18 all four families (OpenAI, Nova, xAI Grok Voice, Google Gemini Live) are `implemented_and_verified` (4 of 4), each with a passing AC-09 artifact bound to a current capability report. Nova and Google exclude the interruption dimension. Reports expire weekly; an expired report returns the family to `implemented_but_unverified` (`REPORT_EXPIRED`).

- `src/voice_harness/adapters/__init__.py`: `LiveAdapter` protocol (MockProvider operations plus `interrupt(item_id, audio_end_ms)`) and closed pydantic events (audio_out, transcript delta/final, tool_call, turn start/end, interrupted, usage, error). Unsupported truncation is signalled by `capabilities()["interrupt_truncate"] == "unsupported"` and `CapabilityUnsupported`.
- `src/voice_harness/resample.py`: stdlib integer linear resampler (any rate pair, 16k<->24k tested), 20 ms chunker. Linear interpolation without an anti-alias filter: adequate for speech fixtures, not a quality claim.
- `coverage.py` (AC-20): state derives from `artifacts/phase0/*-capability-report.json` plus an adapter module being present. `implemented_and_verified` requires: adapter present, report valid, not expired, not failed-closed, and `artifacts/phase2/<family>-ac09.json` with `passed: true`, no failures and a `capability_report_id` equal to the report. Otherwise `implemented_but_unverified` (reasons `REPORT_EXPIRED`, `REPORT_FAILED_CLOSED`, `AC09_NOT_PASSED`, `NO_CAPABILITY_REPORT`); no adapter gives `not_implemented`. xAI Grok Voice and Google Gemini Live gained adapters on 2026-10-18 (see `docs/PHASE4_NOTES_xai.md`, `docs/PHASE4_NOTES_google.md`) and follow the same rules. Nothing is ranked (`ranking: null`) and `verified_count` counts verified states only.
- API: `GET /api/v1/providers` and `GET /api/v1/providers/export` (same payload, with `statement`). Directories overridable by `HARNESS_PHASE0_DIR` / `HARNESS_PHASE2_DIR`. The Docker image now ships the capability reports and `artifacts/phase2/`. **UI (2026-10-17):** `apps/web/coverage.html` (served at `/client/coverage.html`) shows all four families in fixed server order with state, reasons, report age and probe-event count, no ranking or score; operator token entered in-page, data fetched from `/api/v1/providers`, rendered with `textContent` under a strict CSP. View-model tests: `tests/browser/coverage.test.mjs`. Verified by a headless-Chrome render of the real API payload; the token-entry path was covered by API tests only (browser extension was unavailable).
- `tests/adapter_conformance.py` (AC-09 harness): dimensions audio_in, audio_out, tool_result_correlation, interruption, error; unsupported dimensions are `excluded` with a reason, and exclusion of a mandatory dimension prevents `passed`. Proven only against a MockProvider wrapper in `tests/test_phase2.py`. Live runs are opt-in: `VOICE_HARNESS_LIVE_ADAPTERS=openai,aws_nova_sonic` requires each adapter module to expose `conformance_factory() -> (adapter, prime)`; `write_result()` stores the result bound to a capability report.
- **AC-20 export (2026-10-17):** every evidence bundle manifest embeds `provider_coverage` = `summarize(build_registry())` snapshotted at export time (all four families in server order, state, reason codes, report id, checked_at, evidence ids, `statement`, `ranking: null`). It sits inside the manifest, so `manifest_hash` covers it, and `verify_bundle` additionally runs `evidence.coverage_section_valid`: exact family set/order, closed key sets (no score/rank fields), `implemented_and_verified` only with no reason codes and a bound report, non-verified states must carry reasons, counts and statement must derive from items, ranking null. Strictest legacy behaviour: bundles without the section fail verification (re-export required, as with the RFC 8785 change). Because the manifest is unsigned, a re-sealed forgery is caught only by these semantic checks and, for the verified bit, not against the committed AC-09 artifacts (offline verification does not re-derive state). Tests: `tests/test_coverage_export.py`. `artifacts/golden-run.json` is not a bundle and is unchanged.
